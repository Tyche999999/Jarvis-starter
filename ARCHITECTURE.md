# Vault Architecture — Living Map

The current shape of the vault, in service of THE GOAL (see IDENTITY.md). Two jobs: tell you where things live so filing is fast, and show — at a glance — whether the structure still points at THE GOAL or has drifted. Read before filing. Update whenever structure changes.

Terse index: folder → one-line purpose, where the purpose says how it serves THE GOAL. Keep under ~150 lines. When this gets heavy, push detail into nested CLAUDE.md files and leave only a pointer here — the always-on cost stays low.

## Structure
- `IDENTITY.md` — fixed point; THE GOAL and observed profile
- `ARCHITECTURE.md` — this file; vault map
- `00-inbox/` — unsorted capture; staged items awaiting filing
- `10-projects/` — active projects
  - `pipeline.md` — all ideas, sequencing, and status
